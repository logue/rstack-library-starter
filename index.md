## Features

- [🏃🏻‍♀️ **Blazing fast build speed**](/guide/start/introduction): The core compilation module is based on the Rust front-end toolchain, providing a more ultimate development experience.
- [📦 **Support for MDX content writing**](/guide/use-mdx/components): MDX is a powerful way to write content, allowing you to use React components in Markdown.
- [🎨 **Built-in full-text search**](https://rspress.rs/guide/advanced/custom-search): Automatically generates a full-text search index for you during construction, providing out-of-the-box full-text search capabilities.
- [🤖 **AI-friendly**](https://rspress.rs/guide/basic/ssg-md): Generate llms.txt and Markdown files compliant with the llms.txt specification through SSG-MD, making it easier for large language models to understand and use your documentation.
- [🌈 **Static site generation**](https://rspress.rs/guide/basic/ssg): In production, it automatically builds into static HTML files, which can be easily deployed anywhere.
- [🔥 **Providing multiple custom capabilities**](https://rspress.rs/guide/basic/custom-theme): Through its extension mechanism, you can easily extend theme UI and build process.
